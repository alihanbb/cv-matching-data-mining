Senior Python Backend Engineer

Description:
We are looking for an experienced Python backend engineer to design and operate
scalable microservices for our fintech platform. You will own service design,
API contracts, and CI/CD quality.

Responsibilities:
- Design REST APIs and microservices in Python (FastAPI or Django).
- Operate services on Docker and Kubernetes in AWS.
- Build CI/CD pipelines and code review culture.
- Collaborate with data and frontend teams in agile sprints.

Requirements:
- At least 5 years of experience with Python backend development.
- Strong SQL knowledge with PostgreSQL.
- Hands-on Docker and Kubernetes experience.
- Familiarity with Git and CI/CD tools.

Nice to have:
- Experience with Kafka or other message queues.
- AWS or GCP cloud experience.
